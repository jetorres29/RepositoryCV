## About

Machine learning and statistics projects developed during my MSc in Data Science
and Analytics at Universidad EAFIT (2019–2021), implemented in Python, R, and MATLAB.

Topics covered:

* Supervised learning – classification
* Unsupervised learning – clustering
* Face recognition – Eigenfaces with PCA
* Variable selection with frequentist and Bayesian statistics
* Robust and nonparametric statistics

For my current work on AI agents and LLM-based applications, see
[consultoria-lab](https://github.com/consultoria-lab).
